#  R1: DST Survival Project

**Survival-crafting проект в стиле Don't Starve на Roblox.**
Процедурная генерация мира, система биомов, крафт и выживание.

##  Требования к окружению

Перед началом работы убедись, что у тебя установлено:
1.  **Roblox Studio** (последняя версия)
2.  **VS Code** + расширение [Luau Language Server](https://marketplace.visualstudio.com/items?itemName=JohnnyMorganz.luau-lsp)
3.  **Git**
4.  **Aftman** (менеджер инструментов) — *обязательно!*

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/ROBRO-S/R1.git
cd R1
```

### 2. Установка инструментов
Aftman автоматически скачает нужную версию Rojo, указанную в `aftman.toml`:
```bash
aftman install
```
*Проверка:* `rojo --version` должен показать `7.7.0-rc.1`.

### 3. Запуск синхронизации
В терминале из папки проекта:
```bash
rojo serve
```
Ты увидишь: `Serving project 'R1 Project' at http://localhost:34872`

### 4. Подключение Roblox Studio
1.  Открой **любой** пустой Place в Roblox Studio.
2.  Перейди во вкладку **Plugins** → нажми **Rojo**.
3.  В поле адреса должно быть `localhost:34872`. Нажми **Connect**.
4.  Если всё ок — в Explorer появятся папки `Server`, `Shared`, `Client`.

> ⚠️ **ВАЖНО:** Никогда не сохраняй изменения через `File > Save to Roblox`! Весь код управляется через Git и Rojo. Сохраняй только `.rbxl` как локальный бэкап, если нужно.

## 🤝 Workflow для команды

1.  **Перед началом работы:** Всегда делай `git pull origin main`.
2.  **Разработка:** Создавай ветку для каждой фичи:
    ```bash
    git checkout -b feature/my-awesome-biome
    ```
3.  **Тестирование:** Пиши код в VS Code → изменения мгновенно появляются в Studio через Rojo.
4.  **Сдача:** Запушь ветку и создай **Pull Request** на GitHub.
5.  **Code Review:** Жди апрува от тимлида перед мержем в `main`.

> 🚫 **ЗАПРЕЩЕНО:** Пушить напрямую в `main`. Работать одновременно в одном `.rbxl` файле без Rojo.
