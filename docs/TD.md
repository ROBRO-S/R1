## 2. Внешние Инструменты
| Инструмент                 | Назначение                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------- |
| **Cargo**                  | Менеджер пакетов для Rust (для установки пакетов, написанных на Rust)                   |
| **Matter**                 | ECS-библиотека для Roblox Studio ([Документация](https://github.com/matter-ecs/matter)) |
| **Wally**                  | Менеджер пакетов для добавления зависимостей (для пакетов внутри Roblox Studio)         |
| **Rojo**                   | Синхронизатор файловой системы (мост между Roblox Studio и внешним IDE)                 |
| **Среда разработки (IDE)** | VS Code                                                                                 |
