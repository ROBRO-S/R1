Я набросал структуру GDD специально под твой проект (DST-like survival в Roblox). Это скелет. Ты читаешь, правишь, дополняешь, и мы получаем документ, с которым можно идти к команде.

# 📄 GAME DESIGN DOCUMENT: [Название Проекта]
**Версия:** 0.1 (Draft)  
**Автор:** Ismail Tez  
**Платформа:** Roblox (PC/Mobile/Console)  
**Жанр:** Survival / Crafting / Open World  

## 1. High Concept (Концепция)
**Описание:**  
Хардкорный survival-проект в стиле *Don't Starve*, адаптированный под механики Roblox. Игрок попадает в процедурно генерируемый мир, где должен выживать, собирая ресурсы, крафтя инструменты и исследуя уникальные биомы. Ключевая особенность — глубокая система взаимодействия с окружением (сбор веток, рубка деревьев, добыча камня) и атмосферная визуальная стилистика.

**USP (Уникальное торговое предложение):**
*   **Procedural Biomes:** Каждый сервер генерирует уникальный ландшафт с четким разделением на зоны (луга, пустыни, скалы).
*   **Tactile Gathering:** Ресурсы не просто «кликаются», а имеют физическое представление в мире (ветки лежат на земле, камни имеют вес).
*   **Tech-Stack:** Использование Rojo + Git для профессиональной разработки и версионирования контента.

## 2. Core Gameplay Loop (Основной цикл)
1.  **Explore:** Исследование procedurally generated карты.
2.  **Gather:** Сбор базовых ресурсов (Stick, Flint, Log, Stone) вручную.
3.  **Craft:** Создание инструментов (Axe, Pickaxe) и станков (Science Machine).
4.  **Survive:** Управление голодом, здоровьем и рассудком (Sanity).
5.  **Build:** Строительство базы для защиты от ночи/монстров.

## 3. World & Biomes (Мир и Биомы)
*Техническая реализация: Lua Noise Functions + Voxel Terrain*

| Биом | Визуал | Ключевые ресурсы | Опасности |
| :--- | :--- | :--- | :--- |
| **Grasslands (Луга)** | Зеленая трава, пологие холмы, тонкие деревья | Twigs (Ветки), Grass, Berry Bushes | Hounds (Собаки) ночью |
| **Desert (Пустыня)** | Песок, кактусы, отсутствие деревьев | Cactus, Flint, Boulders (Камни) | Heat (Перегрев днем) |
| **Rocky Land (Скалы)** | Серый камень, обрывы, пещеры | Nitre, Gold Nuggets, Marble | Batilisks, Falling Rocks |
| **Forest (Лес)** | Густые высокие деревья, темная земля | Logs, Pine Cones, Mushrooms | Tree Guards (если рубить много) |

**Генерация:**
*   Используется `math.noise` для высоты и распределения биомов.
*   Объекты спавнятся через Raycast для точного позиционирования на рельефе.
*   Плотность объектов регулируется таблицей шансов (Rarity Tables).

## 4. Resources & Items (Ресурсы)
*Принцип: "What you see is what you get"*

*   **Twig (Ветка):** Лежит на земле. Собирается рукой. Нужна для Science Machine и костра.
*   **Log (Бревно):** Выпадает из дерева после рубки топором. Топливо и стройматериал.
*   **Flint (Кремень):** Выпадает из камней или лежит на земле. Нужен для первых инструментов.
*   **Stone (Камень):** Добывается киркой из валунов. Стройматериал.

## 5. Technical Stack (Техническая часть)
*Для команды разработчиков*

*   **Engine:** Roblox Studio
*   **Version Control:** Git (GitHub/GitLab)
*   **Sync Tool:** Rojo 7.x (Live sync VS Code ↔ Studio)
*   **Tool Manager:** Aftman (для управления версиями Rojo/Luau)
*   **Language:** Luau (Typed Lua)
*   **Asset Pipeline:** Модели хранятся в `ReplicatedStorage`, скрипты в `src/server` и `src/client`.

## 6. Art Direction (Визуальный стиль)
*   **Style:** Low-poly, hand-painted textures (как в оригинале DST).
*   **Lighting:** Dynamic day/night cycle. Ночь должна быть *действительно* темной и страшной.
*   **UI:** Minimalist, paper-texture style. Инвентарь — это не список, а сетка слотов.

## 7. Roadmap (Этапы разработки)
1.  **Phase 1 (Core):** Генерация мира, сбор ресурсов, инвентарь, крафт топора/кирки. *(Текущий этап)*
2.  **Phase 2 (Survival):** Голод, здоровье, день/ночь, костер.
3.  **Phase 3 (Mobs):** Пассивные (кролики) и агрессивные (собаки) мобы.
4.  **Phase 4 (Progression):** Science Machine,Alchemy Engine, новые биомы.
5.  **Phase 5 (Polish):** Звуки, партиклы, оптимизация, мобильная адаптация.



Братан, ты абсолютно прав. Пытаться впихнуть болото, пустыню, подземелье и театр на одну карту 2000x2000 — это верный способ получить кашу и лаги. Разделение на **Основной Мир (Overworld)** и **Отдельные Миры/Подземелья** — это профессиональный подход к левел-дизайну в Roblox.

Давай обновим GDD с учетом твоей структуры. Я разбил локации по уровням генерации.

## 1. Структура Мира (World Architecture)

Мы используем систему **"Якорных Биомов"** для основного мира и **"Инстансированных Локаций"** для специфических зон.

### 🌍 Tier 1: Основной Мир (Overworld)
*Единая процедурная карта (2000x2000+ studs). Здесь игрок проводит 80% времени.*

| Биом | Описание | Ключевые объекты (Генерируются случайно) | Ресурсы |
| :--- | :--- | :--- | :--- |
| **Луга (Grasslands)** | Стартовая зона. Ровный рельеф, высокая трава. | Лесополосы, Ульи (Bees), Норы Кроликов, Цветы. | Twigs, Grass, Berries, Honey |
| **Засушливая степь (Savanna)** | Желтая трава, холмы. Зона бизонов. | Стада Бизонов, Кактусы, Ветряные мельницы (декор). | Beefalo Wool, Cactus, Flint |
| **Болото (Swamp)** | Темная вода, туман, вязкая земля. | Щупальца (Tentacles), Паучьи гнезда, Мерцающие грибы. | Reeds, Spider Silk, Tentacle Spikes |
| **Кладбище (Graveyard)** | Мрачная зона, надгробия, сухая земля. | Призраки, Надгробия, Гнилые деревья. | Red Gems, Blueprint fragments |
| **Каменная пустошь (Rocky Land)** | Серый камень, минимум растительности. | Валуны (Boulders), Обрывы, Пещерные входы. | Nitre, Gold, Marble, Flint |

> **💡 Правило генерации:** Крупные биомы (Степь, Болото) занимают 30-40% карты каждый. Мелкие точки интереса (Ульи, Лагеря Свиней, Театр) генерируются как "POI" (Points of Interest) внутри биомов с шансом 5-10%.

### ️ Tier 2: Отдельные Миры (Instance Worlds)
*Не помещаются на основную карту. Загружаются через порталы/лифты. Имеют свою логику освещения и физики.*

| Локация | Тип | Особенности |
| :--- | :--- | :--- |
| **Подземелье (Caves)** | Отдельный Place/Server | Полная темнота + светлячки/фонари. Сталактиты. Светлячки как источник света. |
| **Руины (Ruins)** | Отдельный Place/Server | Древние механизмы, Мех-мобы (Clockworks), Лунный камень. |
| **Арена Мухи (Fly Boss)** | Арена | Закрытое пространство для битвы с боссом. Специфический лут. |

## 2. Система Сезонов (Seasons) - *Отложено (Phase 4)*
*Пока не реализуем, но закладываем архитектуру:*
*   **Autumn:** Стандартный режим.
*   **Winter:** Снег, замерзание воды, Penguin biomes.
*   **Spring:** Дождь, лягушки, рост травы.
*   **Summer:** Перегрев, пожары, Dryness.

> **⚠️ Важно для команды:** Сейчас мы фокусируемся только на **Tier 1 (Основной мир)** и базовой генерации ресурсов. Подземелья и сезоны — это контент для следующих спринтов.

## 3. Технические требования к генерации

1.  **Модульность:** Каждый биом — это отдельный Lua-модуль (`Biome_Grasslands.lua`, `Biome_Swamp.lua`). Это позволит добавлять новые биомы без переписывания ядра.
2.  **POI System:** Мелкие локации (Театр, Лагерь Свиней) — это预фабы (Models), которые спавнятся целиком, а не собираются по блокам.
3.  **Оптимизация:** Использование `StreamingEnabled` для основной карты, так как она будет большой.
4.  **Rojo Sync:** Все модули биомов лежат в `src/Server/Biomes/` и синхронятся автоматически.
